## E-001：Codex 搜索“表格”

来源：发起者提供的会话背景与本次撰写要求。背景涉及不同操作或历史加载状态下的结果差异。本版未完成截图与步骤对应检查，也未独立复现。

待补：原始截图或录屏、实际发生时间（未知可留空）、产品与客户端版本、同一会话和查询条件的确认、操作顺序、结果数量及完整范围、重复实验结果。补证前不引用确定数量。

需要区分：界面匹配数量、会话内查找、全局历史搜索是否属于同一个功能。即使差异复现，也不能仅凭界面现象认定内部索引或加载机制。

## E-002：找回“FLV 无声音”讨论

来源：发起者提供的经历线索。本版未核对原始讨论与检索记录。

待补：原讨论的脱敏片段、实际查询词与查找入口、操作过程、是否最终找回，以及可确认的时间和客户端信息。不要把“未找到”改写为“被删除”，也不要把技术问题本身当作检索系统缺陷。

## 证据维护规则

- 不虚构截图、日期、版本、结果数字或复现记录；未知字段明确写“待补”。
- 发布前移除账号信息、私密对话、密钥与第三方敏感内容，仅提交说明问题所需的最小片段。
- 原始证据、观察说明和机制假设分别记录；助手此前给出的解释不算原始证据。
- 状态变化通过提交记录说明；推翻原观察时同步修正文案。
- 不公开整份聊天记录或本机附件路径。
