## Evidence maintenance rules

- Do not invent screenshots, dates, versions, result counts, or reproduction records. Mark unknown fields as “pending.”
- Before publication, remove account information, private conversations, secrets, and sensitive third-party content. Submit only the minimum excerpts needed to explain the issue.
- Record original evidence, descriptions of observations, and hypotheses about mechanisms separately. Earlier assistant explanations do not count as original evidence.
- Explain status changes in commit history. If an earlier observation is overturned, update the corresponding text.
- Do not publish full conversation histories or local attachment paths.
