# Data Accessibility Decay

[中文](data-accessibility-decay.md) | **English**

**Data Accessibility Decay** is a provisional name used in this project for the following phenomenon:

> Data may remain stored while growth in records, task evolution, and fragmented sources make it increasingly difficult for users to locate, verify, and continue using it.

It is not an established theory, quantitative metric, or factual judgment about all products. The public initiative describes the phenomenon directly rather than depending on a new term.

## Different from data loss

Data loss means the original record no longer exists. Accessibility decay concerns situations where evidence does not establish deletion, yet the user cannot find the record reasonably and reliably. “Not found” does not imply “deleted.”

## Possible contributing factors

These are matters for study, not claims about a particular product's internal implementation:

- users remember an outcome's meaning while task titles preserve initial wording;
- one piece of work spans multiple conversations or AI services;
- remembered keywords differ from the original wording;
- platform search coverage, index coverage, or history presentation is opaque to users;
- AI-generated recollections appear precise but cannot be verified against original records.

## Relationship to the initiative

Products can continue improving search and Memory, but these features cannot replace user access to original data. With authorized, read-only, paginated retrieval and stable incremental positioning, users can preserve and index records independently and establish verification paths that do not depend on one platform's search experience.
